# Imagens públicas

Pasta para armazenar os assets de imagem do site DevLimeira.

## Arquivos esperados

| Arquivo | Uso |
|---|---|
| `logo.png` | Logo completa (horizontal) — fundo transparente ou branco |
| `logo-icon.png` | Apenas o ícone da laranja (sem o texto) — opcional |
| `og-image.png` | Imagem para Open Graph / redes sociais (1200×630px) |

## Notas

- Prefira PNG com **fundo transparente** para melhor resultado no modo escuro.
- Tamanho recomendado para a logo: largura máxima de **400px** (será exibida em 34px de altura na navbar).
- Coloque este arquivo no lugar certo: `public/images/logo.png` (o arquivo estará disponível em `/images/logo.png`).
